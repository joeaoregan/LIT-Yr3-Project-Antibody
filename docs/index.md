## Project Scope (Games Fleadh 2017)

[Games Fleadh](https://tus.ie/gamesfleadh/) objectives for 2017.

- Create a racing game which we can enter in Games Fleadh 2017, and complete this game to a high standard which we can use for our third-year project module.
- The game should have at least 3 levels 
- Our game will include time trial like stages, with objects and enemies trying to slow the player down which will increase the sense of speed and pressure the player feels to try and hit the next checkpoint
- The player must focus on more than one activity at a time adding to the challenge
- Measure our games completeness by the number of completed features on the features list
- A realistic level of success will be reached if we can complete 75% of the features we have laid out beginning with the highest priority
- We have a strict hand up date for Games Fleadh and our project deadline, all code needs to be completed in advance of this deadline to enable us to test the game and it’s features thoroughly
